Steps:

Launch Plant Simulation app then pin to toolbar for easy access

The simulator opens in your browser. Leave the tray icon running while you
use it; right-click it for "Open in browser", "Show log" or "Stop".

Your staff and settings are saved inside this folder (data\), so they are
still here next time you open it.

resources\  - the developer notes (CALIBRATION_NOTES.md), the .bat fallback
              launcher, and the Python package list. Nothing to run day to day.
